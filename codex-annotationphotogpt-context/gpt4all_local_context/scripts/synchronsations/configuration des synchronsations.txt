🔎 Important pour la suite

Pour vos synchronisations NAS ↔ PC fixe :

Toujours utiliser :

ssh -p 2222 sshsync@10.0.1.10


Et pour rsync :

rsync -avz -e "ssh -p 2222" ...


À conserver comme commande “définitive”

rsync --old-args -avz --info=progress2 \
  -e "ssh -p 2222 -i /home/nicolas/.ssh/id_ed25519" \
  --rsync-path='C:\msys64\usr\bin\rsync.exe' \
  /volume1/Affaires/2025-J37/ \
  sshsync@10.0.1.10:/c/Affaires/2025-J37/


Optionnel (plus sûr si vous craignez les fichiers ouverts)

Si vous retombez un jour sur un “device or resource busy (16)” (fichier verrouillé côté Windows), vous pourrez relancer avec :

--inplace (évite le renommage final), ou

--partial --partial-dir=.rsync-partial (reprend mieux)

rsync --old-args -avz --inplace --info=progress2 \
  -e "ssh -p 2222 -i /home/nicolas/.ssh/id_ed25519" \
  --rsync-path='C:\msys64\usr\bin\rsync.exe' \
  /volume1/Affaires/2025-J37/ \
  sshsync@10.0.1.10:/c/Affaires/2025-J37/


2) Exemple de commandes prêtes à l’emploi

En gardant vos paramètres SSH/port 2222 et votre nécessité --old-args + rsync Windows via MSYS2.

A) NAS → PCfixe (numériques)


rsync --old-args -avz --info=progress2 \
  -e "ssh -p 2222 -i /home/nicolas/.ssh/id_ed25519" \
  --rsync-path='C:\msys64\usr\bin\rsync.exe' \
  --exclude '/_DB/***' --exclude '/_Config/***' \
  --include '/*/' \
  --include '/[0-9][0-9]_*/***' \
  --exclude '/*' \
  /volume1/Affaires/ \
  sshsync@10.0.1.10:/c/Affaires/


B) PCfixe → NAS (alphabétiques)

rsync --old-args -avz --info=progress2 \
  -e "ssh -p 2222 -i /home/nicolas/.ssh/id_ed25519" \
  --rsync-path='C:\msys64\usr\bin\rsync.exe' \
  --exclude '/_DB/***' --exclude '/_Config/***' \
  --include '/*/' \
  --include '/[A-Za-z][A-Za-z]_*/***' \
  --exclude '/*' \
  sshsync@10.0.1.10:/c/Affaires/ \
  /volume1/Affaires/
